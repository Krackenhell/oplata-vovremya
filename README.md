# Оплата вовремя

Минимальный рабочий прототип для Академии Финтеха 2026, трек «Финтех без границ».

**Демо:** https://krackenhell.github.io/oplata-vovremya/

**Презентация:** [PDF](presentation.pdf) · [PowerPoint](presentation.pptx)

## Что можно попробовать

1. Открыть счёт «Северного проекта». В переписке есть запрос подписанного акта.
2. Посмотреть найденную цитату и добавить действие ответственному.
3. Подготовить и отредактировать черновик письма. Сервис ничего не отправляет.
4. В разделе «Мои действия» отметить задачу выполненной.
5. Учесть частичное поступление и проверить новый остаток.
6. Скачать образец CSV, изменить данные и загрузить собственный реестр.
7. Добавить текст переписки к счёту и повторить разбор.

## Что работает

- CSV: разделители `;` и `,`, кавычки, многострочный контекст, UTF-8 и Windows-1251.
- Проверка дат, сумм, частичных оплат, дублирующихся счетов и обязательных колонок.
- Расчёт остатка и просрочки на выбранную дату, поиск и фильтры.
- Разбор текста по явным правилам: запрос документа, уточнение суммы, обещание оплаты, нехватка средств.
- Цитата из исходного текста, ручная проверка, подготовка письма.
- Действия ответственным, ручной учёт поступлений, экспорт реестра.
- Сохранение состояния в sessionStorage в пределах вкладки.
- Адаптивная версия для мобильных устройств.

## Границы прототипа

Языковая модель, банковские интеграции, почта, 1С, OCR/PDF и многопользовательский доступ **не подключены**. Разбор выполняется детерминированными правилами и может пропускать сложные формулировки, отрицания и устаревшие сообщения. Найденная цитата является сигналом, а не доказанным диагнозом. Дата в демонстрации: 11 октября 2026 года. Её можно изменить.

Компании, суммы и переписка в демонстрационном наборе вымышлены. Реального исследования пользователей, платящих клиентов и измеренного эффекта пока нет. Прототип не проводит платежи и не подтверждает банковские поступления.

Импорт заменяет реестр и очищает список действий. Перед импортом можно скачать текущий CSV. Файлы и переписка обрабатываются локально, без внешних API. Состояние обычно удаляется при закрытии вкладки, поведение восстановления вкладок зависит от браузера. При использовании общего компьютера сбросьте данные после работы.

## Локальный запуск

Нужен Node.js 20 или новее. Зависимостей приложения нет.

```sh
npm start
```

Открыть http://127.0.0.1:4173.

```sh
npm test
```

## Формат CSV

Обязательные поля: `invoice_id`, `client`, `amount`, `due_date`.
Дополнительные: `paid`, `owner`, `email`, `context`.

Суммы в рублях, даты `YYYY-MM-DD` или `DD.MM.YYYY`. Не более 2 000 строк и 2 МБ. Оплата не может превышать сумму счёта. [Образец](example.csv).

## Следующий этап

Проблемные интервью и разбор обезличенных случаев. Затем подключение модели с проверкой цитат, интеграции и ограниченный пилот. Снижение просрочки и готовность платить требуют проверки.
